# ModelSkills

Reusable ML model development skills for Claude Code. Framework-agnostic guidance for the full model development lifecycle.

## Skills

| Skill | Description |
|-------|-------------|
| `model-experiment` | Full experiment lifecycle: pre-flight → launch → monitor → triage → fix → re-run |
| `monitor-training-runs` | Live monitoring of active training runs: crash detection, loss anomalies, GPU health |
| `memory-optimization` | GPU memory profiling, batch size optimization, gradient checkpointing |

## Usage

Copy individual skill folders to `~/.claude/skills/` or symlink them.
